**Sobre o projeto**

Este projeto consiste no desenvolvimento de uma ferramenta de apoio à organização de informações para o Imposto de Renda, criada durante o Bootcamp DIO + Reclame Aqui, sob orientação do professor Felipe Aguiar (Felipão).

A proposta foi aplicar, na prática, os conceitos e recursos do Excel trabalhados ao longo do módulo, desenvolvendo uma ferramenta funcional, com foco na organização das informações, padronização dos dados e facilidade de utilização.

**Estrutura da ferramenta**

O I.R App foi organizado em três abas principais:

**Titular:** espaço destinado ao preenchimento das informações do titular.

**Informes:** área para registro de informações bancárias.

**Notas:** espaço para inserção e acompanhamento de notas, com totalização automática dos valores informados.

**Recursos e funcionalidades implementados**

Durante o desenvolvimento, foram utilizados diferentes recursos do Excel:

**Navegação entre abas:** inserção de hiperlinks internos para facilitar a movimentação entre as seções da ferramenta.

**Formatação personalizada:** padronização da entrada de informações, como datas e CPF.

**Hiperlinks externos:** criação de links para acesso aos canais relacionados ao desenvolvimento da ferramenta.

**Validação de dados:** implementação de listas suspensas para seleção de instituições bancárias.

**Objetivo de aprendizagem**

O desenvolvimento deste projeto proporcionou a aplicação prática de recursos do Excel, permitindo explorar funcionalidades voltadas à organização, validação e tratamento de informações.

Além do aprendizado técnico, o projeto também possibilitou exercitar o planejamento de uma solução, considerando sua estrutura, apresentação visual e experiência de utilização.

**Além do que foi pedido**

Como proposta, inseri mais duas funcionalidades:

**Campo para outras instituições:** inclusão da opção "0 - Outros", permitindo o preenchimento manual quando o banco desejado não estiver disponível na lista.

**Fórmulas:** utilização da função SOMA para totalização automática dos valores inseridos na aba Notas.
